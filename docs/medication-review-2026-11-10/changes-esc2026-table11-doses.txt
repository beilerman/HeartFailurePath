# Ranking change: Table 11 doses (2026 ESC), 2026-11-11

Changes: (1) spironolactone target is 50 mg (25 mg is the target only at eGFR 45 or below, where the engine's own renal cap is 25 mg); it was 25 or 50.
(2) The sacubitril/valsartan start is 24/26 mg below eGFR 60 (ESC Table 11 optional lower start; the label halves only below 30) and with chronic hypotension
(ESC optional lower start); it was 49/51 unless ACEi/ARB-naive or low dose, eGFR below 30 or Child-Pugh B. The stricter of ESC and label is kept.
(3) In HFpEF a non-forced ACEi/ARB to ARNI swap is no longer offered (the ESC switch recommendation, Class I B1, is for HFrEF; a RAAS inhibitor in
HFpEF is Class IIb and interchangeable). Also edited fixtures: "High Body Weight Carvedilol Target Requires 50 BID" and "Rate-Source Digoxin Sinus Rhythm
Offered After Maximal GDMT" now start on spironolactone 50 mg (at 25 mg a pillar is still titratable, so the scenarios' premise no longer held); their
diff rows below are fixture effects, not engine effects.

Clinical read (what the diff shows, and what is odd):
- Spironolactone 25 mg is now below target outside the renal cap, so every regimen carrying it earns the sub-target completeness credit and a titration to 50 mg
  is offered. Real engine effects: "Adjunct-Source Vericiguat ..." and "A-HeFT Bonus ..." leads now titrate spironolactone to 50 mg (and in the A-HeFT case H/ISDN
  is shown at its 37.5/20 start tier); "Over-Budget Value Ordering" now leads with a carvedilol start instead of a spironolactone 25 mg start (a new MRA start at
  25 mg is below the 50 mg target, like any pillar started at its starting dose); "Third-Degree AV Block Beta-Blocker Removed" prefers dapagliflozin + eplerenone 25 over
  dapagliflozin + spironolactone 25 by under 0.3 raw points.
- Odd, left in place per the "keep the stricter" instruction: "Final-Gaps Ramipril 5 mg bid Counts As Target" (eGFR in the 30-59 band) no longer leads with the
  ACEi to ARNI switch; it keeps ramipril because the ARNI would now start at 24/26 (below the ACEi's dose credit). At eGFR 40 the switch still leads, at 24/26.
  ESC calls the 24/26 start "optional" at eGFR 30-60, so this is a systematic preference for staying on a target-dose ACEi that a prescriber may not share.
