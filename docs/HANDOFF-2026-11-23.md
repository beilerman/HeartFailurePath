## Reproduce the engineering checks

From the repository root, use Node 22 and the checked-in npm lockfile. The first command installs the locked dependencies. The second builds the app and runs the full verification suite, including the default 5,000-patient sweep. The last two repeat the ranking comparison and the second sweep.

```sh
npm ci
npm run ci
npm run ranking:diff
npm exec -- tsx scripts/fuzzSweep.ts 5000 791342
```

For the browser check, start the built app with `npm run preview -- --host 127.0.0.1 --port 4173 --strictPort`. In a second terminal, run the command below. The runner needs Playwright and Chromium. Set `HF_PLAYWRIGHT` to the installed Playwright module or `HF_CHROME` to the browser executable when using a separate installation.

```sh
HF_BASE_URL=http://127.0.0.1:4173 node scripts/verifyBrowserSession.mjs
```
